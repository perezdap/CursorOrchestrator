## 🚀 Quick Start (under 60 seconds)

1. **Install**
   ```bash
   npm install -g cursor-orchestrator
   ```

2. **Init in your repo**
   ```bash
   orchestrator init
   ```

3. **Run a demo**
   ```bash
   orchestrator run --example full-feature
   # or
   orchestrator validate
   orchestrator run
   ```

**Requirements:** Node 20+, PowerShell 7+, Git repo, Cursor
